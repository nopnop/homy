# Confidentiality and Privacy Policy

## Data Collection

**Homy collects NO user data whatsoever.**

This Chrome extension is designed with privacy as a core principle:

- **No Analytics**: No usage statistics, click tracking, or behavioral data collection
- **No Telemetry**: No performance metrics or error reporting sent to external servers
- **No Network Requests**: The extension operates entirely offline and makes no external API calls
- **No User Identification**: No cookies, fingerprinting, or user identification mechanisms

## Data Storage

All data remains exclusively on your device:

- **Local Storage Only**: Bookmarks and settings are stored using Chrome's local storage API
- **Chrome Sync**: When enabled, your data synchronizes through Chrome's built-in sync service (controlled by your Google account settings)
- **No External Servers**: No data is transmitted to or stored on any external servers operated by Homy

## Permissions

The extension requests minimal permissions:

- **New Tab Override**: To replace Chrome's default new tab page
- **Storage**: To save your bookmarks and settings locally
- **Active Tab**: To create bookmarks from the current page (only when you explicitly use the bookmark button)

## Open Source

Homy is completely open source under the MIT License:

- **Source Code**: Available at https://github.com/nopnop/homy
- **Transparency**: Every line of code is publicly auditable
- **No Hidden Functionality**: What you see in the source code is exactly what runs in your browser
